# Scout2Bench

Studio gara dai file DataVolley (DVW): foglio panchina, report battuta, game plan. / Match study from DataVolley (DVW) files: bench sheet, serve report, game plan.

**App:** https://pgiangrossi73.github.io/scout2bench-app/

- Si installa dal browser ("Aggiungi a schermata Home") e funziona anche senza rete. / Install it from the browser ("Add to Home screen"); it also works offline.
- **I dati restano sul dispositivo**: DVW, fogli, report e game plan sono salvati solo nel browser di chi usa l'app; questo sito non riceve nulla. / **Data stays on the device**: nothing is sent to this site.
- L'analisi usa gli script Python originali del metodo STUDIO GARA, eseguiti nel browser con Pyodide (MPL-2.0). Caratteri: Barlow Condensed e Inter (SIL OFL). / The analysis uses the original Python scripts, run in the browser with Pyodide (MPL-2.0). Fonts: Barlow Condensed and Inter (SIL OFL).

Questo repository contiene solo l'app pronta; il codice sorgente è in un repository privato. / This repository holds only the built app; the source code is in a private repository.
